Three things to try

  1. Select a CUB color attribute. Its label is image-level; the highlighted dot is a related part annotation. Turn on proxy boxes to see the extra assumption.
  2. Switch to SVG. Compare the reference bird with the changed bill, crown, and wing. Which changes affect the toy class?
  3. Compare the moved bird and red distractor. Concept presence alone cannot specify location or distinguish a red crown from red background.

What this exercise establishes

CUB: original species labels, binary attributes, certainty, part keypoints, and one bird box. The attribute-to-part mapping and dashed boxes are our construction. They are not concept-box ground truth.

SVG: six photo-textured SVGs, six feathered vector illustrations, and six simple vector drawings, exact filled geometry for the pure-vector sets, exact authored edit masks with approximate anatomical fit for the photo-textured set, and an authored class rule. Flowers: assistant-drawn approximate concept boxes and subjective presence scores; these need human review before use as gold labels.

A correct location annotation does not show that a trained model uses it. This exercise contains no trained classifier predictions or accuracy claims. Flower scores are assistant visual judgments.
